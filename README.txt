МОТОЭКСПЕРТ — учебная версия 4: GitHub Pages + Formspree

Это вымышленный мотосервис, не действующая мастерская. Используйте только вымышленные
данные во всех полях. Подготовлен приём тестов через созданную пользователем форму MOTO.
При выпуске этого комплекта новая публикация и живой тест без VPN ещё не выполнены.
Версия Netlify и исходная копия сайта сохранены отдельно и не изменены.

КАК ОТКРЫТЬ И ОБНОВИТЬ
1. Распакуйте архив целиком. Откройте index.html для просмотра.
   Локально и в предпросмотре отправка намеренно отключена.
2. Публикация: репозиторий ivanmikhailenko011-jpg/motoexpert, папка motoexpert-v2 3.
   Обновлять нужно именно эту папку, а не корень репозитория и не новый репозиторий.
3. В ней замените index.html, styles.css, app.js; добавьте delivery-core.js,
   delivery-ui.js и requests.css. Эти шесть файлов должны лежать рядом.
   assets/ уже есть в прежней публикации и в этом полном комплекте; фото и шрифты
   не менялись. Не создавайте ещё одну вложенную папку вокруг файлов сайта.
4. Дождитесь успешной публикации GitHub Pages и проверьте адрес:
   https://ivanmikhailenko011-jpg.github.io/motoexpert/motoexpert-v2%203/
5. Netlify для этой версии не нужен, его настройки не меняйте.
6. Для отката верните прежние файлы из истории репозитория или сохранённого архива.

КАК РАБОТАЕТ УЧЕБНАЯ ФОРМА
- Сохранены три шага: услуга, мотоцикл и задача, контакт. Есть просмотр ответов,
  возврат к редактированию, очистка и проверка обязательных полей.
- Телефон допускается только вымышленный: +7 000 000-00-00.
- Проверка ответов ничего не отправляет. После подтверждения вымышленных данных
  отдельная кнопка «Отправить тест — новая вкладка» отправляет обычную HTML-форму
  методом POST в https://formspree.io/f/xrppvgzp.
- Это публичный адрес приёма формы, не пароль и не ключ доступа к кабинету.
- Браузер открывает ответ Formspree в новой вкладке. Если сервис покажет проверку
  человека, пользователь проходит её сам. Новая вкладка может получить ошибку сети
  или отказ сервиса; страница сайта этого не скрывает и не обещает успеха.
- Обычный браузерный переход не требует чтения межсайтового ответа из JavaScript.
  Уведомления на почту и Telegram этой сборкой не настроены и не проверены.
- В исходной вкладке повторная отправка, редактирование и очистка блокируются
  после попытки: сначала нужно проверить, сохранился ли запрос.
- В поля не добавляются секреты, токены, cookies или пароль. Нет аналитики,
  localStorage и автоматических повторов. Сервис может хранить переданные сведения.

КАК ПОДТВЕРДИТЬ ПОЛУЧЕНИЕ
1. Откройте обновлённый GitHub Pages без VPN в браузере пользователя.
2. Выберите «Диагностика»; модель «Учебный мотоцикл»; описание «Проверка GitHub Pages
   и Formspree без VPN». Имя/год можно не заполнять. Телефон +7 000 000-00-00.
3. Перейдите к просмотру, сохраните номер test-formspree-… и подтвердите учебные данные.
4. Отправьте ОДИН раз. Посмотрите результат на открывшейся странице Formspree.
5. В кабинете Formspree откройте MOTO → Submissions; найдите тот же номер requestId
   и сверьте услугу, модель, описание и вымышленный телефон.
6. Только совпадающая сохранённая запись подтверждает получение. Открытие сайта,
   новая вкладка или сообщение об отправке сами по себе не подтверждают доставку.
7. Если запись не видна, проверьте доступные в кабинете разделы спама/отклонённых.
   Не повторяйте отправку при неизвестном исходе. Сначала покажите результат помощнику.

ОГРАНИЧЕНИЯ И БЕЗОПАСНОСТЬ
- Блокировка действует на текущей открытой странице, не между устройствами/вкладками.
  requestId — номер для сверки, а не серверная защита от дублей.
- Проверка учебного телефона в браузере обходится технически. Это не серверная
  защита данных и не разрешение собирать реальные клиентские контакты.
- На Free заявлены 50 отправок в месяц и архив в кабинете 30 дней; актуальные
  условия и ограничения проверяйте в своём кабинете. Платные опции не включались.
- Платная настройка собственной страницы «Спасибо» не используется: показывается
  ответ самого Formspree. Поддержка особых honeypot-полей не заявляется.
- Отправка разрешена только с HTTPS-адреса ivanmikhailenko011-jpg.github.io
  в репозитории /motoexpert/. Для другого домена потребуется новая настройка и тест.
- Открытие GitHub Pages/Formspree у пользователя без VPN подтверждено ранее,
  но не гарантирует доступность из других сетей или постоянную доступность.
- Перед реальным запуском нужны настоящие данные сервиса, применимые правила
  обработки персональных данных, ограничения сервера/антиспам и проверка получателя.

ФАЙЛЫ
index.html — структура сайта и адрес приёма; styles.css — исходный дизайн.
app.js — шаги и проверки; delivery-core.js — разрешённый адрес публикации.
delivery-ui.js — учебное подтверждение и блокировка повторов; requests.css — статусы.
assets/ — прежние локальные фото, шрифты и лицензии. Ничего ставить не требуется.

ПРОВЕРКИ ПЕРЕД ВЫДАЧЕЙ
Проверен синтаксис трёх JS-файлов. На ширинах 390, 768 и 1440 px не обнаружены
ошибки загрузки, ошибки скриптов или горизонтальное переполнение. На телефоне
и компьютере проверены обязательные поля, год, длина описания, учебный телефон,
просмотр/редактирование/очистка, текст без исполнения HTML, локальная блокировка,
публичный адрес и состав отправляемых полей, защита от повторного клика.
Нативная отправка и исключение браузера моделировались в памяти тестового браузера,
без внешних POST. Это не проверка сервера Formspree, новой вкладки в Safari,
возможной проверки человека, доставки письма или работы без VPN у пользователя.
Эти пункты проверяются отдельно после публикации, одной учебной отправкой.
